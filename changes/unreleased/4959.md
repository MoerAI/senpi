## 2026-10-30 - A turn-ending notice shows once, live and on replay (senpi#4958)

### What changed

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: the live head row is marked as showing its turn-ending notice elsewhere when a trailing text run exists (`headNoticeShownElsewhere`). A replayed assistant message calls `setOwnsTurnNotice(replayOwnsTurnNotice(message))`, so it shows its own error or abort notice although it holds tool calls.

### Why

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: a length-stopped turn printed its max-token notice on the head and on every text run, and a replayed failed turn with tool calls showed no error row.

### Why an extension could not handle it

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: transcript row ownership is built-in `InteractiveMode` rendering that extensions do not own.

### Expected merge conflict zones

- `packages/coding-agent/src/modes/interactive/interactive-mode.ts`: the head line of `syncTrailingAssistantText`, the `assistant` case of `addMessageToChat`, and the import block.
