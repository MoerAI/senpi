## 2026-10-26 - Sanitize isolated CLI runtime arguments (senpi#2952)

### What changed

- `packages/coding-agent/src/cli.ts`: use `runtimeExecArgv()` for the isolation decision and the child launch, preserving runtime options without replaying the caller's entry mode.
- `packages/coding-agent/dist/cli.js`: regenerate the merged launcher, retaining current presenter-channel and bootstrap behavior.

### Why

- `packages/coding-agent/src/cli.ts`: forwarding raw eval or print arguments executes the embedding caller again instead of the intended CLI child.

### Why an extension could not handle it

- `packages/coding-agent/src/cli.ts`: process isolation is decided before the extension loader runs.

### Expected merge conflict zones

- `packages/coding-agent/src/cli.ts`: the sanitizer import, `requiresIsolatedProcess()` and the argv in `spawnFullCli()`; regenerate `packages/coding-agent/dist/cli.js` from that merged source.
